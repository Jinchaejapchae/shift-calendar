아이폰 시계 알람을
근무표대로 울리게

달력 앱에서 내 조와 대근·연차를 정하면, 아이폰이 매일 밤 내일 근무를 보고 시계 앱 알람을 켜고 끕니다. 처음에 한 번만 만들면 됩니다 (약 15분).

끝까지 울리는 진짜 시계 알람이라 무음 모드에서도 울리고, 애플워치를 차고 있으면 워치도 울립니다.

달력 앱에서 근무 변경 → 위에 뜨는 시계 알람에 반영
→ 단축어 교대알람이 앞으로 400일 근무표를 아이폰에 저장
매일 밤 9시 자동화 → 단축어 교대알람맞추기가 내일 근무를 보고 알람 켜고 끔

1시계 앱에 알람 2개 만들기

  1. 시계 앱 → 알람 → +
  2. 05:30 · 레이블 주간 · 반복 안 함 → 저장
  3. 17:30 · 레이블 야간 · 반복 안 함 → 저장

시각·소리는 원하는 대로 (알람 시각은 시계 앱에서 정합니다).

2단축어 「교대알람맞추기」 만들기

  2. 아래 동작들을 검색해서 순서대로 추가

  • [형식 지정된 날짜]는 글자 칸을 누르면 위에 뜨는 변수에서 고르고, 바로 뒤에 영어 대문자 D/N/O를 붙여 씁니다 (D=주간, N=야간, O=휴무).
  • "알람 켜기/끄기"의 알람을 눌러 1단계 알람을 고르고, 켜기/끄기를 눌러 바꿉니다.

3단축어 「교대알람」 만들기

달력 앱이 이 이름으로 근무표를 보냅니다. 이름을 정확히 교대알람 으로.

파일 저장 · 저장할 것 = 단축어 입력 · 저장할 위치 묻기 끔 · 하위 경로 교대근무.txt · 덮어쓰기 켬
단축어 실행 → 교대알람맞추기
알림 보기 "시계 알람에 반영했어요"
  • 단축어 입력 변수가 안 보이면: 아래 ⓘ(단축어 정보) → 공유 시트에 표시 켜기 → 맨 위 입력 종류를 텍스트로.
  • 저장 위치는 iCloud Drive의 Shortcuts 폴더입니다. 2단계의 「파일 가져오기」도 같은 곳을 봅니다.

4매일 밤 자동화

  1. 단축어 앱 → 자동화 탭 → + → 특정 시간
  2. 시간 오후 9:00, 매일 → 즉시 실행 → 다음
  3. 단축어 실행(또는 내 단축어 목록에서) → 교대알람맞추기 고르기

5달력 앱에서 켜기

  1. 홈 화면의 교대근무 앱(달력)에서 내 조 선택
  2. 오른쪽 위 시계 아이콘 → 아이폰 시계 알람 (단축어) 켜기 → 지금 시계 알람에 반영
  3. 단축어 앱이 열리며 실행됩니다. 처음엔 "파일 접근", "알람 변경" 허용을 물으면 항상 허용
  4. 시계 앱에서 내일 근무에 맞는 알람만 켜졌는지 확인

이후 대근·연차를 바꾸면 달력 앱 위쪽에 "아이폰 시계 알람에 아직 반영되지 않았어요" 줄이 뜹니다. 시계 알람에 반영만 누르면 됩니다. 근무표는 400일치라 1년쯤 지나면 같은 줄이 다시 뜹니다.

!알아 둘 것

  • 알람은 내일 것만 맞춥니다. 오늘 근무를 바꿨다면 오늘 알람은 시계 앱에서 직접 켜고 끄세요.
  • 밤 9시 이후에 근무를 바꿨다면 반영만 누르면 내일 알람이 바로 맞춰집니다.
  • 아이폰이 꺼져 있던 밤에는 자동화가 실행되지 않습니다.
  • 캘린더 구독도 해 두었다면 짧은 캘린더 알림이 같이 울립니다. 싫으면 설정 → 캘린더 → 계정 → 구독한 캘린더 → 알림 제거.
