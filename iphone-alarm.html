아이폰 시계 알람을
근무표대로 울리게

달력 앱에서 정한 조·대근·연차대로 아이폰 시계 앱 알람이 켜지고 꺼집니다. 처음에 한 번만 설정하면 됩니다.

내일 주간
주간 알람 켬, 야간 알람 끔
내일 야간
야간 알람 켬, 주간 알람 끔
내일 휴무
둘 다 끔

끝까지 울리는 진짜 시계 알람이라 무음 모드에서도 울리고, 애플워치도 같이 울립니다. 매일 밤 9시에 내일 것을 맞추고, 낮에 대근을 반영하면 오늘 남은 알람까지 맞춥니다.

1시계 앱에 알람 2개

  1. 시계 앱 → 알람 → +
  2. 05:30 · 레이블 주간 · 반복 안 함 → 저장
  3. 17:30 · 레이블 야간 · 반복 안 함 → 저장

시각·소리는 원하는 대로. 레이블은 글자 그대로 주간, 야간이어야 합니다. 단축어가 이 이름으로 알람을 찾습니다.

단축어 받기

  2. 추가가 안 되면(아이폰 버전이 낮은 경우) 아래 직접 만들기로

만약 종료
  • 6시간이 맞습니다 (1일 아님). 밤 9시에 돌면 내일, 낮에 [반영]을 누르면 아직 안 울린 오늘 알람을 맞춥니다.
  • [형식 지정된 날짜]는 글자 칸을 누르면 위에 뜨는 변수에서 고르고, 바로 뒤에 영어 대문자 D/N/O 를 붙입니다 (D=주간, N=야간, O=휴무).
  • "알람 켜기/끄기"(전환)의 알람 칸은 목록의 알람을 직접 고르지 말고 변수 선택에서 위 알람 찾기의 결과를 고릅니다 (주간/야간에 맞게).
  • "중단 및 출력" 동작이 생겼으면 지우세요 (뒤 동작이 실행되지 않음).
  • 마지막에 오른쪽 위 완료.

3매일 밤 자동화

  1. 단축어 앱 → 아래 자동화 탭 → + → 특정 시간
  2. 오후 9:00 · 매일 · 즉시 실행 → 다음
  3. 목록에서 교대알람 고르기

애플이 막아 두어서 자동화만은 각자 만들어야 합니다 (터치 5번).

4달력 앱에서 켜기

  1. 홈 화면 교대근무 앱 → 내 조 선택 → 오른쪽 위 시계 아이콘
  2. 아이폰 시계 알람 (단축어) 스위치 켜기 → 단축어 앱이 열리며 바로 반영
  3. 처음엔 "붙여넣기", "파일 접근", "알람 변경" 허용을 물으면 모두 항상 허용
  4. 시계 앱에서 내일 근무에 맞는 알람만 켜졌는지 확인

✓평소에는

  • 그냥 두면 됩니다. 매일 밤 9시에 내일 알람이 맞춰집니다.
  • 대근·연차를 바꾸면 달력 앱 위에 알림 줄이 뜹니다 → 시계 알람에 반영 한 번.
  • 잠시 쉬려면 같은 스위치를 끄기. 알람이 꺼지고 밤에도 꺼진 채로 있습니다. 다시 켜면 근무표대로.
  • 야간 알람을 18:00 이후로 정했다면, 18:00부터 그 알람 전까지는 [반영]을 누르지 마세요 (내일 기준으로 맞춰져서 오늘 알람이 꺼질 수 있음).
  • 캘린더 구독도 해 두었다면 짧은 캘린더 알림이 같이 옵니다. 싫으면 설정 → 캘린더 → 계정 → 구독한 캘린더 → 알림 제거.
