아이폰 시계 알람을
근무표대로 울리게

매일 저녁 9시에 아이폰이 내일 근무를 확인해서 시계 앱 알람을 켜고 끕니다. 처음에 한 번만 만들면 됩니다 (약 10분).

내일 주간
주간 알람 켬, 야간 알람 끔
내일 야간
야간 알람 켬, 주간 알람 끔
내일 휴무
둘 다 끔

끝까지 울리는 진짜 시계 알람이라 무음 모드에서도 울리고, 애플워치를 차고 있으면 워치도 울립니다.

1근무표 캘린더 구독

  1. 달력 사이트 위쪽 달력 아이콘 → ○조 근무표 구독하기
  2. 이미 구독했으면 건너뛰기. 캘린더 이름은 D조 교대근무 처럼 나옵니다 (내 조)

대근 반영 파일(캘린더 파일 받기)을 쓰는 경우엔 그 파일을 넣은 캘린더를 아래 3단계에서 고르면 됩니다.

2시계 앱에 알람 2개 만들기

  1. 시계 앱 → 알람 → +
  2. 05:30 · 레이블 주간 · 반복 안 함 → 저장
  3. 17:30 · 레이블 야간 · 반복 안 함 → 저장

시각·소리는 원하는 대로. 레이블은 나중에 단축어에서 고를 때 구분용입니다.

3단축어 자동화 만들기

  1. 단축어 앱 → 아래 자동화 탭 → + (또는 새로운 자동화)
  2. 특정 시간 → 시간 오후 9:00, 매일 → 즉시 실행 선택 (실행 시 알림은 꺼도 됨) → 다음
  3. 새로운 빈 단축어 → 아래 동작들을 검색해서 순서대로 추가

만약 종료
  • "만약"에서 캘린더 이벤트를 누르면 제목을 고를 수 있습니다.
  • 시작 날짜에 내일임이 없으면 다음 기간 이내 · 1 · 일로 하세요 (저녁 9시 기준 내일 일정이 잡힘).
  • "알람 켜기/끄기"의 알람을 눌러 2단계에서 만든 알람을 고르고, 켜기/끄기를 눌러 바꿉니다.

4확인

  1. 단축어 편집 화면 오른쪽 아래 ▶ 를 눌러 한 번 실행
  2. 시계 앱에서 내일 근무에 맞는 알람만 켜졌는지 보기 (내일 휴무면 둘 다 꺼짐)

!알아 둘 것

  • 대근·연차: 구독 캘린더는 고칠 수 없어서 대근은 반영되지 않습니다. 그날은 시계 앱에서 알람을 직접 켜고 끄거나, 달력 사이트의 캘린더 파일 받기(대근 반영)를 쓰고 그 캘린더를 3단계에서 고르세요.
  • 밤 9시 이후에 근무가 바뀐 걸 알게 되면 단축어를 직접 한 번 실행하면 됩니다.
  • 캘린더 알림(짧은 알림음)도 같이 오는 게 싫으면: 설정 → 캘린더 → 계정 → 구독한 캘린더 → 알림 제거 켜기.
  • 아이폰이 꺼져 있던 밤에는 자동화가 실행되지 않습니다. 근무 전날엔 알람 상태를 한 번 확인하세요.
